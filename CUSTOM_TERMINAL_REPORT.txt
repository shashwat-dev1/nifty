CUSTOM PAGES AND WORKFLOW
Match explorer, KP calculator, Intraday timeline, Overview, Backtesting, Data
manager, Research lab, Settings and Feedback are connected to actual services.
The three-table workflow shows planets, saved matches, then genuine outcomes.
There are 61,790 searchable cached configurations. Modes: exact five ruling
lords, partial signature, selected-planet sign/nakshatra/sub-lord, KP score range,
and circular longitude tolerance. Only earlier timestamps qualify.
Features are versioned by engine hash and reproducibly cached. Background feature
generation supports daily times or 1/5/15/30-minute session grids, with resumable
batches up to ten years per submitted range, independently of price availability.
Server pagination limits responses. Table sorting, search and local CSV exports
apply to the displayed page. Columns can be hidden; planetary details expanded.
Demo export controls are disabled. Source datasets are not publicly served.

For matches, genuine reference and 5/15/30/60-minute prices, point changes and
percent changes are attached. Missing prices stay null. All-match statistics
report data availability, complete windows, positive/negative/flat observations,
mean/median point changes and observed positive frequency. This is not a calibrated
future trading probability. Daily and intraday research remain separate.

Candles are stored at interval-close timestamps. Provider opening labels shift
forward by their interval. Reference/forward closes are descriptive index changes,
not executable fills. Every minute must exist inside the same session date, so
holidays, gaps, breaks and closing boundaries are not bridged with daily prices.
Charts use genuine OHLC with 1/5/15-minute complete aggregates, IST labels,
crosshair, zoom/pan, selected timestamp, reference line, highlighted horizon and
endpoint. No invented traded index volume. Optional daily fallback/KP overlay
are not implemented.
